# 研修スケジュール管理

座学研修のスケジュール(いつ・どこで・何を・何時から何時まで)を管理するブラウザアプリです。
ビルド不要で `index.html` を開くだけで動きます。データはブラウザ内(localStorage)に保存されます。

## 組み直しを楽にする仕組み
- コマには「長さ(分)」と「前との空き(分)」だけを持たせ、**開始・終了時刻は自動計算**します。
  長さを変えると、その日の後ろのコマが自動で後ろへずれます。
- コマはドラッグ(または ↑↓)で並べ替え、別の日・未配置へ移動できます。
- 日付は「この日以降を1営業日ずらす」「全体を◯営業日ずらす」「開始日を変更」で一括変更(土日、設定により祝日も飛ばす)。
- 「複製」で前月のスケジュールをコピーし、開始日を変えて来月分を作れます。
- 終了時刻が目安(既定18:00)を超える日、同じ日付が重なった日を警告します。

## 担当部署・担当者のプルダウン
- 日ごとの画面のコマの行から、担当部署と担当者を直接プルダウンで選べます(編集画面を開かなくても変更できます)。入力画面の「担当(部署)」「担当者」もプルダウンです。初期値は、担当部署が イネーブル / 総務/経理 / 人事 / コンプラ部 / 社長 / 商品部 / 総務/事務 / 営業事務 / FC部 / 経理、担当者が 崎浦 / 原澤 / 田村 / 白川 / 三輪 / 山嵜 / 中山 / 古田 / 古田/中山 / 古田/山嵜 / 柚木 / 千代田 です(以前の保存データにも自動で追加されます)。
- 後から追加できます: 入力画面の「追加・編集」、または画面上部の「担当部署の設定」「担当者の設定」から、追加・名前の変更・並べ替え・削除ができます。名前を変えると、すべてのスケジュールの該当コマも変わります。
- シートの取り込みで、一覧にない部署名・担当者名が使われているときは、設定画面に「＋ 名前」のボタンが出て、ワンクリックで一覧に加えられます(一覧にない名前もそのコマには残ります)。
- 共有している全員で同じ一覧を使います。

## 研修終了日
- 月ごとのスケジュールに「研修終了日」を入力できます(「日程の一括変更・設定」の中。任意)。日ごとの画面の該当日に「研修終了日」の印、月カレンダーに「研修終了」の印、年間表示に下線が付きます。
- 終了日より後に研修日があると警告します。「＋ 月を追加」では、ひな形から作った最後の研修日が初期値で、変更できます(変更すると、はみ出す日数をプレビューで確認できます)。
- 共有している全員に反映され、変更履歴からも戻せます。

## 共有(クレードを使わない方法): Googleスプレッドシート + Apps Script
- 保存先は、あなたの Google ドライブのスプレッドシートです。**Google アカウントのない人も使えます**(URL と「合言葉」で入ります。編集用と閲覧用の2種類)。
- 手順は [docs/共有のはじめかた.md](docs/共有のはじめかた.md) にあります。Apps Script に12ファイル(`apps-script/` の `Config.gs`・`Web.gs`・`Api.gs`・`Write.gs`・`Store.gs`・`Index.html`・`Part_Style.gs`・`Part_Js1〜4.gs`・`appsscript.json`)を貼って、ウェブアプリとして公開するだけです。
- Apps Script がアプリの画面も配るので、共有する URL は1つです。画面の「共有の設定」から、編集用・閲覧用の共有リンクをコピーして配れます。
- 他の人の変更は15秒ごとに取りに行きます。同じ日を同時に編集した場合は、後から保存した内容になります。
- `node tools/build_apps_script.js`(最初の1回だけ `cd tools && npm install`)で画面のファイル(`Index.html` など)を作り直せます。貼り付けやすいよう、圧縮してあります。サーバー側の確認は `node tools/test-gas.js`(Google に載せずに試せる模擬環境つき)です。

## 共有(claude.ai で公開する方法)
- claude.ai に公開したページとして開くと、共有データベースに保存され、開いている全員が同じ内容を見られます。他の人の変更は自動で反映されます(日ごとに保存するので、別の日を同時に編集しても衝突しません。同じ日を同時に編集した場合は、後から保存した内容になります)。
- 編集できるのは、共有メニューで「Contributor」以上にした人です。「Viewer」「Commenter」の人は閲覧のみ(編集操作は自動で隠れますが、資料のリンクは開けます)。
- 各日に「最終更新: 誰が・いつ」を表示し、変更履歴には誰の変更かも残ります。
- `index.html` をそのまま開いた場合(共有機能のない環境)は、従来どおりそのブラウザだけに保存します。
- 初回は、同じ場所で以前にこのブラウザへ保存したデータがあれば「このブラウザの保存データを共有に移す」で共有に移せます。

## 資料URL
- 各コマに資料のURL(Googleスライド・ドライブ・動画など)を何件でも登録でき、一覧にリンクとして表示されます(http/https のみ)。
- シートへの書き出し・取り込みでは、資料の列に「名前 URL」の形で入ります。.ics にも含まれます。

## 月ごとのスケジュールと履歴
- スケジュールは月ごとに1つ。「＋ 月を追加」で、前の月をひな形に次の月を作ります(日付は平日に割り振り、日と日の間隔は営業日数で保ちます。完了・テスト結果はリセット)。
- 研修日は基本平日ですが、**祝日も研修を行う**前提です(「祝日を飛ばす」設定は既定でオフ)。土日に研修が入っている日だけ警告します。
- 以前の月のスケジュールはそのまま残り、`<` `>` や一覧で切り替えて見られます。
- 変更履歴: 編集のたび(10分おき)・日をずらす/削除などの大きな操作の前に、変更前の状態を自動保存します(最大30件)。「変更履歴」から、その時点に戻せます(戻す前の状態も残ります)。

## ジャンル
- コマにジャンルを付けて分類できます。初期ジャンルは現行シートの「会社理解・業界理解・他部署理解・法律理解・数字理解・商材理解・顧客理解・自己理解・マインドセット・キャッチの技術・査定の技術・その他」です(「ジャンル設定」で追加・改名・色変更)。
- 色分け表示、ジャンルごとの合計時間、ジャンルでの絞り込みができます。シートの取り込み時、ジャンル列が無ければ研修内容から推測します(あとで直せます)。

## 日ごとの並べ方
- 「並べ方」で、日ごとの表示を切り替えられます(この端末だけの設定)。
  - **1日ずつ縦に**(既定) / **2日ずつ横に**
  - **週ごとに(暦の月〜金)**: 1行が実際の暦の1週間(月〜金)で、研修のある日は曜日の列に並びます。研修のない日は「研修なし」の空き枠になり、「＋ この日に追加」で日を作れます。研修のない週は「研修なし」の1行に畳みます。土日に研修がある場合は、その週は土日の列も出します。
- フリック: 日ごとの画面を左へはじくと次のページ、右へはじくと前のページへめくれます(スマホ・タブレット)。PCのトラックパッドの横スワイプでも同じです。入力欄・ボタン・ドラッグ用のつまみの上では反応しません。
- ページ送り: 日ごとの画面は**5日ずつ**(週ごと表示は**1週間ずつ**)のページに分かれます。上下の「前の5日/次の5日」か、ページ選択で移動でき、「すべて表示」で全日を並べることもできます。日を追加したときや、カレンダーの日をクリックしたときは、その日のページへ移ります。
- ドラッグ操作: コマは別の日・空き枠へ移せます(空き枠へ落とすとその日が作られます)。日カードの「⋮⋮」をドラッグすると日付を移動できます(研修のある日へ落とすと入れ替え)。

## カレンダー表示
- 「月カレンダー」「年間」で、実際の暦(曜日・祝日)の上に研修日を色付けして表示します(祝日は2026〜2027年を内蔵)。
- 月表示の各日に、時刻・研修内容・会場が載ります。日をクリックすると日ごとの表示へ移動します。
- カレンダー上で日をドラッグして日付を移動(研修日同士は入れ替え)、未配置のコマを日へドラッグして追加できます。
- 土日は既定で非表示(「土日も表示」で切替、土日に研修日があれば自動で表示)。年間表示は全月の研修日をまとめて表示します。
- 「カレンダー(.ics)」で書き出すと、Googleカレンダー等へ取り込めます。

## 既存スプレッドシートとの連携
- 取り込み: 現行シート(日程/会場/時間/分/担当/担当者/研修内容/テスト/目的/詳細/資料/進捗/memo)の表をコピー&貼り付け、またはCSVで読み込めます。時刻の入っていない行は「未配置」になります。
- 書き出し: 「シートへ貼付用コピー」で同じ列構成のまま貼り戻せます。CSV / カレンダー(.ics) / JSON / 印刷にも対応。
