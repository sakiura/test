# 研修スケジュール管理

座学研修のスケジュール(いつ・どこで・何を・何時から何時まで)を管理するブラウザアプリです。
ビルド不要で `index.html` を開くだけで動きます。データはブラウザ内(localStorage)に保存されます。

## 組み直しを楽にする仕組み
- コマには「長さ(分)」と「前との空き(分)」だけを持たせ、**開始・終了時刻は自動計算**します。
  長さを変えると、その日の後ろのコマが自動で後ろへずれます。
- コマはドラッグ(または ↑↓)で並べ替え、別の日・未配置へ移動できます。
- 日付は「この日以降を1営業日ずらす」「全体を◯営業日ずらす」「開始日を変更」で一括変更(土日、設定により祝日も飛ばす)。
- 「複製」で前月のスケジュールをコピーし、開始日を変えて来月分を作れます。
- 終了時刻が目安(既定18:00)を超える日、同じ日付が重なった日を警告します。

## カレンダー表示
- 「月カレンダー」「年間」で、実際の暦(曜日・祝日)の上に研修日を色付けして表示します(祝日は2026〜2027年を内蔵)。
- 月表示の各日に、時刻・研修内容・会場が載ります。日をクリックすると日ごとの表示へ移動します。
- カレンダー上で日をドラッグして日付を移動(研修日同士は入れ替え)、未配置のコマを日へドラッグして追加できます。
- 土日・祝日に研修が入っている日は警告します。
- 「カレンダー(.ics)」で書き出すと、Googleカレンダー等へ取り込めます。

## 既存スプレッドシートとの連携
- 取り込み: 現行シート(日程/会場/時間/分/担当/担当者/研修内容/テスト/目的/詳細/資料/進捗/memo)の表をコピー&貼り付け、またはCSVで読み込めます。時刻の入っていない行は「未配置」になります。
- 書き出し: 「シートへ貼付用コピー」で同じ列構成のまま貼り戻せます。CSV / カレンダー(.ics) / JSON / 印刷にも対応。
