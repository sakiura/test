# 研修スケジュール作成アプリ

研修の日程(科目・日時・講師・場所)を登録して、スケジュールを作成・共有するブラウザアプリです。
ビルド不要で、`index.html` をブラウザで開くだけで動きます。データはブラウザ内(localStorage)に保存されます。

## 主な機能
- 科目の追加・編集・複製・削除(種別: 講義/演習/グループワーク/実習/試験・発表/その他)
- 繰り返し登録(毎営業日・毎週)
- 一覧表示(日ごと)と週表示(時間軸)
- 講師・場所の時間重複を自動検出して警告
- 出力: CSV(Excel対応)、カレンダー(.ics)、JSON(保存/読込)、印刷
- 「サンプル読込」で1週間分の新入社員研修例を表示
