# 共有のはじめかた(Googleスプレッドシート版)

クレード(claude.ai)を使わずに、複数人で同じスケジュールを見て、編集する方法です。
Google アカウントを持っていない人も使えます(URL と「合言葉」で入ります)。

- データは、あなたの Google ドライブのスプレッドシートに保存されます。
- 新しく契約するものはありません。作業は一度だけで、10分ほどです。

---

## 準備(一度だけ)

### 1. スプレッドシートを作る
Google ドライブで、新しいスプレッドシートを作ります(名前の例: `研修スケジュール(共有データ)`)。

### 2. Apps Script を開く
スプレッドシートの上のメニューから **拡張機能 → Apps Script** を開きます。

### 3. ファイルを置く(7つ)
このリポジトリの `apps-script/` フォルダの中身を、Apps Script に1つずつ貼り付けます。
**ファイルは小さく分けてあります**(どれも約2.5万文字以内)。1つずつ、確実に貼り付けられます。

| 順 | ファイル | Apps Script での作り方 | 貼り付け後の先頭 → 末尾 |
| --- | --- | --- | --- |
| 1 | `Config.gs` | 最初からある `コード.gs` の中身を全部消して、これを貼る(名前は `Config` に変えても、そのままでも構いません) | `/**` → `}` |
| 2 | `Web.gs` | 左の「ファイル」の **＋ → スクリプト**、名前は `Web` | `// ---------- 入口 ----------` → `}` |
| 3 | `Api.gs` | **＋ → スクリプト**、名前は `Api` | `// ---------- API ----------` → `}` |
| 4 | `Write.gs` | **＋ → スクリプト**、名前は `Write` | `// 1つの集まりを条件で絞って返す…` → `}` |
| 5 | `Store.gs` | **＋ → スクリプト**、名前は `Store` | `// ---------- シートの読み書き ----------` → `}` |
| 6 | `Index.html` | **＋ → HTML**、名前は `Index`(拡張子は自動で付きます) | `<!DOCTYPE html>` → `[[END-OF-Index]]` |
| 7 | `Style.html` | **＋ → HTML**、名前は `Style` | `<style>` → `[[END-OF-Style]]` |
| 8 | `Js1.html` | **＋ → HTML**、名前は `Js1` | `<script>` → `[[END-OF-Js1]]` |
| 9 | `Js2.html` | **＋ → HTML**、名前は `Js2` | `<script>` → `[[END-OF-Js2]]` |
| 10 | `Js3.html` | **＋ → HTML**、名前は `Js3` | `<script>` → `[[END-OF-Js3]]` |
| 11 | `appsscript.json` | 左の **歯車(プロジェクトの設定)** で「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れ、出てきたファイルの中身を置き換える | `{` → `}` |

すべて貼ったら保存(💾)します。

> **コピーのコツ**: 画面上のプレビューは、長いファイルを約100行で区切って表示することがあります。
> ファイルを**ダウンロードして**メモ帳などで開き、全選択(Ctrl/⌘+A)→コピーしてください。GitHub なら、ファイルを開いて右上の「Raw」を押し、全選択→コピーでも取れます。
> 1ファイルずつ貼り付けるたびに、上の表の「先頭 → 末尾」が合っているかを見てください。
>
> **貼り付けのエラーの見方**: 保存したときに「構文エラー」と出たら、出たファイル名のファイルを、もう一度貼り直してください(そのファイルだけ途中で切れています)。
> HTML のファイルが途中で切れているときは、ウェブアプリを開いたときに「画面のファイル(Js2)が最後まで貼り付けられていません」のように、どのファイルかを教える案内が出ます。そのファイルだけ貼り直してください。
>
> 画面のファイル(`Index`・`Style`・`Js1`〜)は、アプリを変更したときに `node tools/build_apps_script.js` で作り直せます(最初の1回だけ `cd tools && npm install` が必要です)。

### 4. 合言葉をつくる
関数の選択欄で **`setup`** を選んで **実行** します。最初は「権限を確認」と出るので、自分のアカウントで許可してください
(「Google hasn't verified this app」と出たら、詳細 → 「(安全ではないページ)に移動」で進めます。自分で作ったスクリプトのためです)。

スプレッドシートに **「設定」** というシートができ、2つの合言葉が書かれます。

- **編集用の合言葉** … 見る・書く
- **閲覧用の合言葉** … 見るだけ

### 5. ウェブアプリとして公開する
右上の **デプロイ → 新しいデプロイ** を選びます。

- 種類の選択(歯車): **ウェブアプリ**
- 次のユーザーとして実行: **自分**
- アクセスできるユーザー: **全員**

**デプロイ** を押すと、`https://script.google.com/macros/s/…/exec` という URL が出ます。これがアプリの URL です。

> 「全員」は、Google アカウントのない人も使えるようにするための設定です。URL を知っているだけでは中身は見えず、合言葉が必要です。

## 使いはじめる

### あなたが最初に開く
アプリの URL をブラウザで開くと、「合言葉を入れてください」と出ます。**編集用の合言葉**と、あなたの表示名(例: 崎浦)を入れて「接続する」を押します。

前から使っているデータがある場合は、画面の「このブラウザの保存データを共有に移す」で、共有側に移せます。
スプレッドシート(研修スケジュール表)の内容は、「取り込み」から貼り付けられます。

### 他の人に配る
アプリ画面上の **「共有の設定」** を開くと、**共有リンク**が出ます。

- **編集用** … 開くだけで、編集できる状態で入れます
- **閲覧用** … 見るだけ(編集の操作は出ません)

相手には、リンクを送るだけです(LINE・メールなど)。**合言葉が入っているので、共有したい人にだけ**送ってください。

## 知っておくこと

- **反映は15秒ほどかかります。** 他の人の変更は、画面を開いている間、15秒ごとに取りに行きます。
- **同じ日を同時に編集したときは、後から保存した内容になります。** 別の日の編集どうしはぶつかりません。
- **誰が変更したかは、表示名で記録されます。** 表示名は本人が決めるもので、本人確認はしていません。
- **データのシートは、直接編集しないでください。** (`schedules`・`days` などのシート。画面に反映されなくなります。)
- **合言葉の変更**: 「設定」シートの右の欄を書き換えます(反映まで数分かかることがあります)。変えると、古い合言葉の人は入れなくなります。
- **バックアップ**: スプレッドシートを「コピーを作成」するだけで取れます。画面の「変更履歴」からも、以前の状態に戻せます。
- **利用の上限**: Apps Script には1日あたりの実行時間の上限があります(個人の Google アカウントで90分、Google Workspace で6時間)。画面を開いている人が10人ほどなら、通常の範囲に収まります。

## アプリを更新したとき
`.gs` や HTML を貼り替えたら、**デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン: 新バージョン → デプロイ** で反映します(URL は変わりません)。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「合言葉が違います」 | 「設定」シートの値と一致しているか。前後に空白が入っていないか |
| 「共有サーバーにつながりません」 | URL が `/exec` で終わっているか。デプロイの「アクセスできるユーザー」が「全員」か。ネットワークが使えるか |
| 「画面のファイル(○○)が最後まで貼り付けられていません」と出る | 案内に出た名前のファイルの中身をすべて消して、同じ名前の `.html` の全文を貼り直す(上の「コピーのコツ」を参照) |
| 「画面のファイル(○○)が見つかりません」と出る | 左の「ファイル」に、その名前の HTML ファイルがあるか確認する |
| 開くと Google のログイン画面が出る | デプロイの「アクセスできるユーザー」が「全員」になっていない。デプロイを管理 → 編集で直す。**会社の Google Workspace で作った場合**は、アドレスが `…/a/macros/会社のドメイン/s/…` の形になり、これだとログインを求められることがあります。`…/macros/s/…/exec`(`/a/macros/ドメイン` の部分を除いた形)を試してください。アプリの「共有の設定」に出る共有リンクは、この形で作られます |
| 「アクセスできるユーザー」に「全員」が出ない | 会社の管理者が、社外への公開を制限しています。管理者に許可を依頼するか、個人の Google アカウントでスクリプトを作り直してください |
| 変更が反映されない | 15秒ほど待つ。それでも駄目なら画面を再読み込みする |
| 「共有への保存に失敗しました」 | 閲覧用の合言葉で入っていないか(閲覧用は書けません) |

## アプリの画面を別の場所に置く場合
`index.html`・`style.css`・`sync-sheet.js`・`app.js` の4つを、社内のサーバーや GitHub Pages などに置いても使えます。
画面の「共有の設定」で、Apps Script の URL と合言葉を入れてください(共有リンクは `…/index.html#share=…` の形になります)。
